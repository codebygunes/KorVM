# Contributing to KorVM

Thank you for your interest in contributing to **KorVM**! We welcome contributions that align with our Zero-Trust security and high-performance execution goals.

## Development Workflow
1. Fork the repository and create your feature branch (`git checkout -b feature/amazing-feature`).
2. Ensure all tests and fuzzing suites pass successfully (`python tests/integration/test_impossible_e2e.py`).
3. Commit your changes with clear, descriptive commit messages.
4. Push to your branch and open a Pull Request.

Please make sure to adhere to our modular milestone principles and code safety guidelines.
